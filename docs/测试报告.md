# 首版测试报告

测试环境：2026-10-09；macOS 26.6.2；Chrome 155.0.8059.40；Node.js 25.1.0；Python 3.9.6。

## 工具与运行

使用 Node 自带 node:test 与 node:assert/strict，Python使用标准库unittest。无测试框架下载要求。

1. 在项目目录打开终端。
2. 执行 `npm test`（或 `node --test tests/*.test.js`）。退出码0且fail为0表示本轮通过。
3. 执行 `python3 -m unittest discover -s tests -v`。末尾显示OK表示通过。需要允许本机临时端口。
4. 新增用例时把“输入→预期结果”写清楚；修改业务逻辑后重新运行全套测试。

例如：

```javascript
const p = {...posts[0], ownerId: 'owner'};
assert.throws(() => C.close(p, 'other'));
const out = C.close(p, 'owner');
assert.equal(out.status, 'closed');
assert.equal(p.status, 'active');
assert.throws(() => C.close(out, 'owner'));
```

这段测试同时覆盖拒绝非发布者、允许发布者、原对象不被副作用改变、拒绝再次结束四个业务结果。Python还向真实HTTP服务发送不同凭证的请求，防止只有页面按钮被隐藏却没有服务端权限校验。
