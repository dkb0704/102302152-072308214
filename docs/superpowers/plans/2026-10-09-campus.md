# 校园失物招领实施计划

> 使用 superpowers:executing-plans 在当前会话逐项实施。

Goal: 可直接打开的完整原型实现及可选共享服务。
Architecture: 原生UI + 纯函数业务规则 + 本地/API适配器；Python SQLite提供共享数据和权限校验。
Tech Stack: HTML/CSS/JavaScript, Node test, Python3.9+ unittest/sqlite3/http.server。
Spec: docs/superpowers/specs/2026-10-09-campus-design.md

## Global Constraints
无第三方运行依赖；Chrome可file打开；长度40/60/100/500；仅lost/found与active/closed；不伪造人工耗时和测试。

## Review Focus
- 存储损坏或配额满时不丢数据或显示成功（任务1）。
- 异常时间、空白和Unicode长度边界（任务1、2）。
- 非发布者直接发API请求、返回体凭证泄漏（任务2）。
- HTTP服务不可用时不退回另一份本地数据（任务1、3）。
- 取消确认后的状态/刷新一致性、快速重复提交（任务3）。
